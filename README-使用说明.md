# 洋芋日记 使用说明

这是一个本地网页应用，包含：每日随机励志诗词 + 人生进度（出生 2004-11-03，按 80 岁估算）+ 出生天数、46 周三阶段训练计划（减脂→增肌→塑形，每周四练：周一推 → 周二拉 → 周三蹲 → 周五美型补强）、按阶段与久坐消耗计算的饮食与三大营养素、每日体重/腰围/肩围与主项力量追踪（含做组重量自记、下次自动显示上次重量），以及计划依据的顶刊文献专栏。

## 电脑上直接用

双击打开 `index.html` 即可使用（推荐用 Chrome 或 Edge 浏览器）。数据自动保存在本浏览器中，关闭再打开不会丢。

## 装到苹果手机（iPhone，可选）

1. 在电脑上打开 [Netlify Drop](https://app.netlify.com/drop)，把整个「备考训练App」文件夹拖进去，等几秒会得到一个网址（形如 xxx.netlify.app）。不需要注册账号。
2. 用 iPhone 的 Safari 浏览器打开该网址。
3. 点 Safari 底部的「分享」按钮 → 往下滑找到「添加到主屏幕」→ 确认添加。
4. 之后主屏幕上会出现「洋芋日记」图标，点开全屏使用，支持离线。

> 提示：这个应用没法上架苹果 App Store（需要开发者账号和审核），但「添加到主屏幕」的效果和 App 一样，免费且够用。

## 每天怎么用

- **今天**：今日训练勾选（主项勾选自动记录重量）、今日饮食勾选（含阶段与营养素标签）、每日体重/腰围/肩围记录。
- **计划**：46 周三阶段总览与任意一周的完整课表（每 4 周一个小周期，第 4 周减载）。每周四练：周一推（卧推/借力推/上胸/中束/三头）、周二拉（宽握引体/划船/面拉/二头）、周三蹲（深蹲/硬拉/单腿/小腿）、周五美型补强（实力推主项 + 上胸/中束/后束/背阔第二次刺激 + 跳跃）。主项重量自记（点「记录」输入，下次自动显示上次做组重量）；主项末组 RIR 0-1（动作变形即停组），辅项 RIR 2-3。
- **文献**：计划依据的顶刊与专著专栏——每条给结论 + 在本计划里怎么落地（周期化、力量、爆发、营养、恢复、目标设定）。
- **饮食**：按减脂/增肌/塑形三阶段分别给出训练日 A/B/C 与休息日模板，标注热量与 P/F/C 三大营养素（热量按"全天久坐、不含训练"计算，训练日含练前加餐，额外运动自己加碳水）。
- **身体**：记录体重/腰围/肩围（建议每周日早上空腹量），自动画趋势线；主项力量曲线自动从训练勾选生成。
- **设置**：导出/导入数据、复制今日训练日志（可粘贴进 Obsidian 知识库训练日志）。

## 数据备份

数据只存在当前设备浏览器里（电脑和手机是各自独立的数据）。建议每周在「设置 → 导出全部数据」保存一次 JSON 文件；换设备时用「导入数据」恢复，手机上的文件可以存到「文件」App 再导入。

## 关键规则（来自训练计划）

- 46 周三阶段：W1-16 减脂·技术期 → W17-36 增肌·力量期 → W37-46 塑形·冲刺期；每 4 周一个小周期，第 4 周减载。
- 组数×次数：4×5 = 4 组每组 5 次；4×3-5 = 每组 3-5 次按状态取；减载周 = 回落小周期起始重量、次数下调。主项末组 RIR 0-1（接近力竭），动作变形立即停组。
- 每个训练日都标了预计时长（约 75-85 分钟，减载周缩短 10 分钟），计划页有"阶段 × 训练分配"表：减脂期中容量、增肌期高容量、塑形期低容量高强度。
- 主项与跳跃类组间休息 3-5 分钟，辅助 60-90 秒；速度掉 20% 即停组。
- 减脂期"条件加重"：上组留 ≤2 次余力（RIR≤2）才 +2.5kg，RIR 3 保持不加；增肌期才按周稳定加重。第 1-2 周先用 5RM 校准起始重量。
- 全面开发身体：力量（推/拉/蹲）+ 爆发（跳跃/摸高）+ 单腿稳定 + 核心控制 + 柔韧拉伸；长跑/折返等体测专项按考后安排自行加入，不在本计划内。
- 美观重点一周两次：上胸（周一/周五）、中束（周一/周五）、后束（周二面拉 + 周五反向飞鸟）、背阔（周二宽握引体 + 周五轻容量），引体用宽握练宽度。
- 蛋白质：减脂/塑形期 150g/天，增肌期 145g/天；坚果 8-10g/天替代炒菜油；生米 1g ≈ 熟饭 3g。
- 第 1 周自 2026-08-10（周一）开始，应用按当天日期自动匹配。
